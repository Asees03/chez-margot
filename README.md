# Chez Margot

A French-inspired restaurant website featuring a cosy Parisian atmosphere, delicious dishes, and a welcoming design.

### Features

* Home page with a hero banner.
* Menu section displaying French dishes and prices.
* About section introducing the restaurant.
* Contact details and reservation form.
* Footer with opening hours and social media links.
* Responsive layout for different screen sizes.

### Technologies Used

* HTML5
* CSS3

### Project Structure

text
Chez-Margot/
├── index.html
├── style.css
└── README.md
```

### How to Run

1. Download or clone the project.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in your web browser.

**Note:** The reservation form is a front-end design and does not currently process bookings.
